# Krishnanunni Prabhakaran | QA Leadership Portfolio

Personal portfolio site built with plain HTML, CSS and JavaScript. No build step.

## Files
- `index.html` for content and structure
- `style.css` for styling and responsive layout
- `script.js` for navigation, case study toggles and reveal effects

## Run locally
Open `index.html` in a browser

## Notes
- Case studies are generalized and contain no confidential company data
- The release health graphic is illustrative
