CASE STUDY / 03

Automation & AI-driven testing

Building automation capability from the ground up and exploring how AI agents can support mobile game QA.

Challenge

Develop repeatable automation capability for mobile game testing while exploring where AI-driven approaches could add value to QA workflows.

Approach

Built automation frameworks from the ground up, using tools including AltTester and Airtest, developed an AI-agent-based testing approach, and added on-demand build sanity checks that report to Slack before full QA starts. The focus is on creating a foundation that can evolve with project needs rather than treating automation as a one-off script.

Leadership angle

This work combines hands-on technical initiative with a broader QA objective: expanding testing capability, improving repeatability and evaluating new approaches responsibly.
